# Accounts

`GuestAccountService` атомарно привязывает оплаченный гостевой заказ к пользователю,
создаёт аккаунт при необходимости и ставит письмо в очередь после commit.

Письмо с временным паролем шифруется в очереди и отправляется через отдельный
`MAIL_CREDENTIALS_MAILER`. Транспорт `log`, `array` и небезопасные цепочки
аварийного переключения для таких писем отклоняются.
