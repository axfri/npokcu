# Deliveries

`ProxyDeliveryService` идемпотентно создаёт тестовые файлы на приватном диске,
связывает их с оплаченными позициями заказа и ставит уведомления в очередь.
Скачивание выполняется отдельным контроллером после проверки Policy, срока действия
и наличия файла, а результат фиксируется в `download_logs`.
